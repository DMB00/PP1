# pythonProject1
## Цель проекта:
Создать виджет, который показывает несколько последних успешных банковских операций клиента.

## Установка:
1. Клонируйте репозиторий:
```
git clone https://github.com/DMB00/PP1.git
```
2. Установите зависимости:
```
pip install mypy
pip install isort
pip install black
pip install pytest
```
